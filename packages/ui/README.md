# @portfolio/ui

Design system package: tokens (colors, type scale, spacing, radius, shadow, blur) and framework-agnostic primitives (GlassPanel, Button, Link, Heading, Text, Container, VisuallyHidden, FocusRing).

Tokens will be exposed as both TypeScript constants and a Tailwind v4 `@theme` layer so they can be consumed by the shell's Tailwind pipeline and any framework (React, Angular, vanilla).

**Status**: Phase 0 placeholder. Real contents arrive in Phase 2 after fetching the design system from the Anthropic API.
