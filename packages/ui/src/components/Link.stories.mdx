# Link

Cyan anchor with thin underline, bloom on hover, composite focus ring. `external`
prop sets `target="_blank"`, `rel="noreferrer noopener"`, and appends a ↗ glyph
so the affordance is legible without relying on color alone.

## In-shell routing

For react-router transitions, wrap the router's `Link` with this className:

```tsx
import { Link as RouterLink } from 'react-router';
// and compose:
<RouterLink to="/en/projects" className={linkClassName}>Work</RouterLink>
```
