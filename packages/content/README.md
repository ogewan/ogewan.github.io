# @portfolio/content

i18n strings (English / Spanish), MDX bodies, and static copy used by the shell and the Angular timeline. Locale files live under `locales/en/` and `locales/es/`.

The Angular timeline reads strings from this package via a small adapter so the Spanish switch flows through every framework in the bundle.

**Status**: Phase 0 placeholder with empty locale directories. Real content arrives across Phases 2, 4, 5, and 6.
